How I work

The part that isn't the model

01

Ground it in real data

An LLM with no retrieval will answer confidently and wrongly. I put a vector index in front of the model so responses are anchored to the documents the user actually has — and so I can point at the source when someone asks where an answer came from.

02

Assume the input is hostile

Anything reaching a model from a user is untrusted. Input sanitisation, structured prompt isolation, and an automated suite of adversarial payloads that runs on every change — because prompt injection is a test you either wrote or didn't.

03

Instrument the cost

Token spend is invisible until the invoice arrives. I record cost per call, persist it somewhere queryable, expose spend by user and operation, and set a daily budget alert — so the surprise happens on a dashboard, not in a finance meeting.

04

Make the write actually happen

Fire-and-forget async writes lose data quietly, which is the worst way to lose it. Awaited transactional commits mean a request doesn't return until the record exists. Unglamorous, and the reason the numbers can be trusted later.
